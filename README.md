# FlockCare – Gamefowl Management and Tracking System

## Description
FlockCare is a web-based Gamefowl Management and Tracking System designed to help gamefowl farm owners organize and monitor their chickens and farm activities. The system provides a centralized way to manage chicken information, classifications, breeding records, health monitoring, feeding activities, farm supplies, and expenses.

## Initial Database Tables

| Table                     | Description      |
| ------------------------- | ---------------- |
| `chickens`                | Chicken records  |
| `chicken_classifications` | Chicken types    |
| `breeding_records`        | Breeding records |
| `health_records`          | Health records   |
| `feed_records`            | Feed records     |
| `supplies`                | Farm supplies    |
| `expenses`                | Farm costs       |
